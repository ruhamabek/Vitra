# Details

The small things that make this site feel finished. People notice them without naming them; apply the ones that fit your project.

- **Frosted glass**: 2 surfaces blur what's behind them (backdrop-filter), usually headers, menus and overlays.
- **Scroll snapping**: Scrolling settles on whole items or sections (scroll-snap).
- **OpenType features**: The type uses OpenType features: character variants cv01; stylistic set ss03; tabular figures; lining figures. Turn on the same ones (font-feature-settings / font-variant-numeric) where the font supports them.
- **Balanced line breaks**: Headings and paragraphs wrap evenly (text-wrap: balance / pretty) on 14 elements: no lonely last words.
- **Blend modes**: 18 elements blend into what's behind them (mix-blend-mode).
- **Filters**: Images and shapes are treated with blur (21), drop-shadow (12).
- **Shaped edges and fades**: 7 clip-path shapes and 22 masks cut or fade edges instead of hard rectangles.
- **Selection colour**: Selected text is rgb(255, 255, 255) on lch(43.1246 53.3774 288.431) (::selection).
- **Focus ring**: Keyboard focus shows as box-shadow rgba(0, 0, 0, 0.1) 0px 4px 12px, rgba(0, 0, 0, 0.2) 0px 0px 0px 2px (:focus-visible).
- **Styled scrollbars**: Scrollbars are restyled to match the interface.
